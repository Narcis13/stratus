# Reply target list — the Track B X List

**Generated 2026-08-03** from `people` (1,800 rows), filtered to `followers_count BETWEEN 10000 AND 500000 AND retired=0`.

## What this is for

Track B of week 1 (Aug 4–10) tests whether **reply targeting** — not reply volume — is what's
broken. Baseline to beat: **17 impressions/reply** (Aug 2: 37 replies → 646 impressions).

The criteria we agreed on:

> post is **<60 min old**, author has **10k+ followers**, post already has **≥10 replies**

X search has **no follower-count operator** — not in the web dialect, not in API v2. So the
"10k+ followers" half cannot be expressed as a query. This list solves it structurally instead:
put these handles in one X List, sort the List timeline by **Latest**, and every author on it
is pre-qualified. The other two criteria you read off the post itself.

**Build the List private.** A public List of people you're about to reply to reads badly, and
the members get notified.

## How to work it

1. Build a **private** X List with all 64. (Bulk-add is faster from the profile hovercards than
   from the List UI.)
2. Pin the List so it's a tab next to Following.
3. Sort by **Latest**.
4. Reply only when the post is **<60 min old** and already has **≥10 replies**. If it has 2
   replies, skip it — you're buying the conversation's reach, not the author's.
5. Substance only: a specific fact, number, or lived experience. Never agreement. No one-worders
   — that's what produced 17 impressions/reply.
6. ~30/day, same volume as now. **The volume is not the variable this week; the targets are.**

## Search fallback (when the List is quiet)

Paste into x.com search, click **Latest**:

```
(AI OR "AI agents" OR coding OR founders OR SaaS) min_replies:10 min_faves:25 -filter:replies -filter:links lang:en
```

```
min_replies:40 min_faves:100 (AI OR work OR career OR jobs) -filter:replies -filter:links lang:en
```

The second finds the biggest live conversations on the platform regardless of author — that's
the borrowed-distribution play that earned 27k/23k/21k on throwaway replies inside your own
viral thread on Jul 17.

## Caveats

- Follower counts come from `people`, captured by DOM hover at varying dates. Treat them as
  approximate and re-check anyone near the 10k floor.
- The band cuts at 500k deliberately: above that your reply is one of thousands and the
  conversation moves too fast to be seen. Below 10k the borrowed distribution isn't worth the
  slot.
- This list is a **week-1 instrument**, not a permanent roster. If Track B clears 60
  impressions/reply, it becomes the daily intake and is worth automating (the search
  query-builder plan). If it doesn't, replies get demoted and this file is retired.
